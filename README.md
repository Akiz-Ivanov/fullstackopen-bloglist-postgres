Solutions for **Part 13** of the **Full Stack Open** course by the University of Helsinki.

This repository contains a backend blog application built with **Node.js**, **Express**, **PostgreSQL**, and **Sequelize**. The exercises cover working with relational databases, migrations, model associations, authentication, session management, and automated testing.

## Features

- RESTful API with Express
- PostgreSQL database using Sequelize ORM
- Database migrations
- User authentication with JWT
- Session management and logout functionality
- Blog CRUD operations
- Reading lists with read/unread status
- Author statistics
- Automated integration tests
- GitHub Actions CI

## Tech Stack

- Node.js
- Express
- PostgreSQL
- Sequelize
- JWT
- Axios
- Node.js Test Runner

## Getting Started

### Install dependencies

```bash
npm install
```

### Configure environment variables

Create a `.env` file and provide the required environment variables (such as your database connection string and JWT secret).

### Start the server

```bash
npm start
```

### Run the tests

```bash
npm test
```
